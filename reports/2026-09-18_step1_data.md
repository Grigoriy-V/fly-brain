# Шаг 1. MaleCNS правая оптическая доля как коннектом в форме FlyVis

Дата: 2026-09-18. Запуск: `2026-09-18_step1_malecns_R_w5` (правая доля, порог веса ≥5). Локально, без Modal, без субагентов. Строки в `reports/runs.jsonl`.

## 1. Что сделано

- Скачаны три файла MaleCNS v1.0 (аннотации 14,5 МБ, нейромедиаторы 43,3 МБ, веса связей 1,05 ГБ; CC-BY 4.0) и предобученный ансамбль FlyVis 1.2.0 (9,4 МБ, 50 моделей). Хеши и источники в `data/manifest.json`. Таблица `olmatching.tsv` из `flyconnectome/ol_annotations` лежит в `data/bridge_olmatching_raw.tsv` (в манифест не внесена, отмечено ниже).
- Через neuPrint (`male-cns:v1.0`) установлена схема: колонки в `assignedOlHex1/2` (осевые, 1–36 и 1–39), мост к FlyWire в `flywireType`, суперклассы `ol_intrinsic`, `ol_sensory`, `visual_projection`, `visual_centrifugal`, и колоночные ROI `ME|LO|LOP_<side>_col_<hex1>_<hex2>` с числом синапсов на нейрон, по ~880 колонок на нейропиль.
- Построен мост типов FlyVis → MaleCNS (`data/bridge/types.csv`, код `flydream/data/bridge.py`).
- Домашняя колонка для каждого нейрона оптической доли по колоночным ROI (`flydream/data/columns_roi.py`), проверена по тегам MaleCNS; медиана партнёров оставлена запасным методом (`flydream/data/optic_lobe.py`).
- Экспорт фильтров «тип → тип → смещение» в форме `ConnectomeFromAvgFilters` (`data/ol/filters_R.json`, код `flydream/data/export.py`) и сравнение с `fib25-fib19_v2.2.json` из FlyVis.
- Ориентация гексагональных осей MaleCNS относительно FlyVis (`flydream/data/orientation.py`).

## 2. Мост типов

| Вид соответствия | Типов FlyVis | Как |
|---|---|---|
| exact | 49 | то же имя в MaleCNS |
| pooled | 8 | R1–R6 в MaleCNS один тип `R1-R6`; R7 = R7y/p/d/unclear, R8 = R8y/p/d/unclear (по `flywireType`) |
| renamed | 2 | Am = `Lai` (olmatching.tsv, `flywireType`); TmY9 = TmY9a + TmY9b |
| compartment | 2 | CT1(Lo1), CT1(M10) = один нейрон CT1 на сторону |
| unmatched | 4 | Mi3, Mi11, Mi12, Tm28: номенклатура FIB-25 (Takemura 2013), отсутствуют в MaleCNS, olmatching, `flywireType`, `hemibrainType` |

Итого 61 из 65 узлов FlyVis имеют соответствие. Остаток из четырёх типов в FlyVis это малые популяции; на шаге 2 они либо исключаются из модели, либо получают медианные параметры без клеток.

**Фоторецепторы.** У них нет стороны сомы (сетчатка вне объёма ЦНС) и нет колоночных тегов. Из 3 377 тел `R1-R6` 1 982 помечены «Out of scope», 1 351 «Reviewed»: ламина реконструирована не полностью (то же отмечено в olmatching для Lai). Сторона взята по большинству постсинаптических партнёров, колонка по ROI ламины отсутствует (колоночные ROI есть только для ME, LO, LOP), поэтому у фоторецепторов колонка берётся по медуллярным терминалям R7/R8 и по партнёрам для R1–R6. Это слабое место экспорта, см. §6.

## 3. Колонки

| Метод | Покрытие правой доли | Точность на 13 267 тегированных нейронах (15 типов) |
|---|---|---|
| ROI по синапсам | 50 906 из 51 875 | точно 0,969; в пределах 1 колонки 0,975 |
| медиана партнёров (запасной) | 934 сверх ROI | точно 0,958; в пределах 1 колонки 0,986 |
| нет колонки | 35 | |

По типам ROI-метод даёт ≥0,993 для 14 типов и 0,529 для Tm4. Tm4 в MaleCNS помечен колонкой не по месту своих синапсов в медулле, и оба метода с ним расходятся. Записано как ISS-0001. Для модели используется ROI-колонка, теги служат проверкой.

Почему не медиана партнёров как основной метод: колонка нейрона, выведенная из колонок его входов, стягивает все смещения «вход → нейрон» к нулю, и структура направленной селективности T4/T5 исчезает. Это было видно по центроидам до перехода на ROI.

## 4. Ориентация осей

Перебраны 104 целочисленные матрицы с det ±1 и элементами в [−2, 2]. Косинусная близость фильтров с FlyVis по общим парам типов: лучшая 0,690 (M = (−1, 0; 1, −1)), худшая 0,648, а пять ближайших кандидатов, повороты решётки, отличаются на 0,005. Сам по себе этот счёт ориентацию не определяет. Определяют центроиды смещений направленно-селективных входов после отображения:

| Пара | FlyVis (u, v) | MaleCNS после M |
|---|---|---|
| Tm9 → T5a | (0,50; −1,00) | (0,34; −0,84) |
| Tm9 → T5b | (−0,50; 1,00) | (−0,28; 0,95) |
| Tm9 → T5c | (−0,77; 0,00) | (−0,60; 0,16) |
| Tm9 → T5d | (0,77; 0,00) | (0,60; 0,17) |
| Mi9 → T4b | (−0,55; 0,97) | (−0,38; 0,94) |
| Mi9 → T4c | (−1,23; 0,30) | (−0,71; 0,10) |
| Mi9 → T4d | (0,45; 0,23) | (0,73; 0,11) |
| Mi9 → T4a | (0,02; −0,40) | (0,41; −1,12) |

Четыре подтипа T5 и три из четырёх T4 совпадают по направлению. Полная таблица в `data/ol/orientation_R.json`.

Для сравнения, неопубликованные оценки сообщества на тех же данных: 75,8% пар, знаки 97,1%, ранговая корреляция 0,79. Наши числа того же порядка. 75 пар FlyVis без аналога в MaleCNS и 24 пары с расхождением знака перечислены в `data/ol/filter_comparison_R.csv`; их разбор это часть шага 2.

Определение фильтра здесь: сумма синапсов по всем парам клеток «источник → цель» с данным смещением, делённая на число клеток источника с колонкой. У FlyVis усреднение шло по семи колонкам FIB-25, так что абсолютные значения сопоставимы лишь по рангу.

## 6. Что не сделано и что слабо

- Фоторецепторы: у R1–R6 нет колоночных ROI (ламина без колоночной разметки), колонка идёт от партнёров; для строгой модели входа нужен эталон по картриджам ламины. Открыто.
- Ламина не полна: около 60% тел R1–R6 «вне объёма». На шаге 2 вход R1–R6 стоит задавать по решётке, как в FlyVis, а не по реконструированным аксонам.
- Tm4 (ISS-0001).
- Левая доля не экспортирована; код принимает `side = "L"` в `config.toml`, запуск не делался.
- `olmatching.tsv` скачан вне манифеста.
- Тесты: три офлайн-теста на чистые функции; синтетического мини-коннектома под `tests/fixtures/` ещё нет.

# 16: источник сна внутри модели. Задача, состояние, план

Дата 2026-09-20. Агент: Claude (Fable). Статус: **проект, не решение** — план
после слова человека. Формулировка задачи — человека (2026-09-20): «я хочу не
находить видео, а генерировать/создавать их, получить реальный „сон“ … найти
источник мозговой активности, которую мы сможем снять, и на её основе
сгенерировать видео»; уточнено: источник — внутри модели, задача одна.

## 1. Задача

Модель нуль (MaleCNS, 60 типов зрительной доли, параметры FlyVis) должна
**сама порождать состояния T4/T5 без видео на входе**, а декодер 13B —
превращать их в видео. Контур:

```
внутренний драйв → мозг (модель нуль + то, чего в ней нет) → состояние T4/T5 (снято)
                 → генератор 13B → видео → тот же мозг → совместимость (прогонка)
```

«Сон» здесь = видео, наиболее совместимое с состоянием, которое мозг
породил сам. Не утверждение о субъективном опыте мухи (AGENTS).

## 2. Что уже есть и чего не хватает

**Есть.** Правая половина контура: 13A/13B читают T4/T5 в один проход
(прогонка 0.03, контроль ≈ 1–3), инверсия как reference. Пункт 11 показал,
что даёт модель нуль без видео: шум во все клетки → тихая рябь; серый вход
→ стационарное состояние. То есть **у модели нуль нет собственной динамики**:
без входа она затухает.

**Чего не хватает — источника.** Посчитано по экспорту MaleCNS
(`data/ol/edges_R_w5.parquet`, `neurons_R.parquet`, 2026-09-20):

- Модель нуль — не чистый прямой проход: в 60 типах есть обратные и
  центробежные типы FlyVis (C2, C3, Lawf1/2, TmY3/4/15, Mi13, Am). Внутри
  самой лестницы обратных связей почти нет: из 593 k синапсов между её 14
  типами «глубже → раньше» всего 18 k, из них 16.6 k — Mi1 → L1.
- **На лестницу приходит 1.69 M синапсов; 25 % (419 k) — от типов,
  которых в модели нуль нет**, потому что их нет во FlyVis: Dm12/4/1/9/10
  (дистальная медулла, 108 k), Pm2b, LPi2b, TmY16/19a, Y12/Y13. Это
  внутренние нейроны медуллы и лобулярной пластинки — именно те, кто
  замыкает петли.
- **T4/T5 отдают 1.50 M синапсов, из них 91 % (1.37 M) — в типы, которых
  в модели нет**: LPi34/21/12/3412/43 (интра-пластиночные, 320 k), VS,
  Y11, Tlp13/14, LLPC1, Am1, TmY20. В модели нуль выход T4/T5 уходит в
  никуда; в коннектоме он идёт в LPi, которые возвращаются на T4/T5
  соседних слоёв (моторная оппонентность), и в VS/HS. Ближайшая к T4/T5
  рекуррентная петля — T4/T5 → LPi → T4/T5 — в модели отсутствует.

Вывод: источник динамики без входа надо *добавлять*, и коннектом говорит
где: недостающие внутренние типы зрительной доли, прежде всего LPi и Dm/Pm.
Центральный мозг (EPG, helicon, R5 из docx человека) — следующий круг, не
первый.

## 3. План, три уровня драйва

Каждый уровень — отдельный измеримый шаг; следующий начинается, если
предыдущий не даёт состояний, которые декодируются выше контроля.

**16.1 Структурный спонтанный драйв в модель нуль как есть** (дёшево, день).
Не белый шум в каждую клетку (п. 11), а шум, похожий на спонтанную
активность: пространственно-временно коррелированный (гауссово поле на
решётке, τ 50–200 мс, масштаб 2–5 колонок), поданный (а) в фоторецепторы,
(б) в L1–L3, (в) в T4/T5 напрямую; амплитуда — по sd активности от клипов.
Снять T4/T5, декодировать 13B, прогонка, контроли: перемешанные клетки и
время. Вопрос шага: рождает ли прямой мозг из структурного шума
что-то, что декодер читает как сцену, а не как шум? Ожидание: (а)–(б) дадут
«шум в глаз» с движением, (в) — то, что 13B видит на неполной маске.
Modal ≈ $0.05.

**16.2 Замкнуть петли зрительной доли** (главный шаг, 2–4 дня). Вернуть в
сеть типы, отброшенные фильтром экспорта, начиная с тех, что замыкают петли
на лестницу: LPi (все), Dm12/4/1/9/10, Pm2b, TmY16/19a, Y11–13; их
синапсы — из экспорта (веса по числу синапсов, как у остальных); знак — по
нейромедиатору MaleCNS (LPi, Dm, Pm — тормозные, глутамат/ГАМК), постоянные
времени и bias — значения FlyVis по умолчанию для типа такой роли. Это
«свои» параметры без обучения (AGENTS: обучение только от пересаженных
весов; здесь их нет — значит без обучения, с проверкой). Обязательно перед
любой картинкой: **проверка устойчивости** сети с петлями при dt 0.02
(длинный прогон без входа: затухает / стационарна / осциллирует /
расходится) и что валидация модели нуль (DSI, вспышка, направление) не
сломана. Затем 16.1 повторить на сети с петлями: есть ли теперь
самоподдерживающаяся активность T4/T5 после снятия входа (послеобраз,
бегущие волны, оппонентные паттерны), и что из неё декодирует 13B.
Modal ≈ $0.2–0.5 (симуляции длиннее, сеть больше).

**16.3 Центральный мозг как драйв** (за веткой, по docx человека). EPG /
helicon / R5 активны ночью сами; их проекции в зрительную долю есть в
MaleCNS. Требует расширения экспорта за пределы зрительной доли — исходная
долгосрочная идея проекта.

## 4. Что считается результатом

Для каждого уровня одна картинка по правилам AGENTS: строка = драйв,
колонки = состояние (карта T4a) / видео 13B / прогонка / контроль. Числа:
прогонка сэмплов против контролей (перемешанные клетки, перемешанное
время); r между сэмплами при одном драйве и разных z; для 16.2 — длина
жизни активности после снятия входа (мс до затухания) и спектр.
«Интересно» = состояние, которое (1) не затухает само, (2) декодируется
выше контролей, (3) не воспроизводится белым шумом. Красивая картинка без
(2) — свойство прайора 13B, не мозга (docx человека, п. 6).

## 5. Что уже известно и не повторяется

- Белый шум в нейроны → рябь (п. 11): 16.1 начинает со структурного шума.
- Полное T4/T5-состояние однозначно задаёт видео (13B (a)): «сон» с полным
  состоянием — одно видео на состояние; разброс появится только если сам
  мозг даёт неполное/нестационарное состояние.
- Огрубление до разрешения реальных записей и сшивка с живой мухой — не
  задача этой ветки (человек, 2026-09-20).

## 6. Решения, которые нужны от человека

2. Для 16.2 — параметры недостающих типов без обучения (знак по
   медиатору, τ и bias по умолчанию), с проверкой устойчивости и
   валидации как воротами.
3. Считать «сном» видео 13B от состояния, порождённого мозгом без входа,

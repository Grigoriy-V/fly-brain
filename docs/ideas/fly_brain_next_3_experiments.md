# Fly Brain — 3 дешёвых эксперимента после 13B

## 1. Hand-written brain prompts

Цель: перестать брать state из исходного видео и проверить генерацию напрямую из вручную заданной нейронной активности.

Pipeline:

`synthetic T4/T5 state → 13B SiT → generated video → frozen brain → state'`

Примеры состояний:
- движение вправо / влево;
- expansion / looming;
- rotation;
- travelling wave;
- локальная активность только в части поля зрения;
- конфликтующие направления.

Главная проверка: насколько `state'` после обратной прогонки совпадает с исходным synthetic state.

Смысл: показать, что модель не просто реконструирует видео, а реально генерирует новое видео из состояния мозга, которого никакое входное видео не создавало.

---

## 2. Counterfactual brain editing

Цель: использовать brain-state как пространство управления и редактирования видео.

Pipeline:

`video → brain state → edit state → 13B → edited/generated video`

Примеры редактирования:
- поменять T4a ↔ T4c;
- повернуть directional channels на 90°;
- изменить активность только слева / справа в поле зрения;
- заменить motion-pattern одной области на другой;
- перенести часть motion-state из одного клипа в другой;
- усиливать / подавлять отдельные направления или типы.

Проверки:
- round-trip по заданным и полным T4/T5;
- насколько изменилось движение / структура видео;
- насколько результат зависит от edit, а не от prior модели.

Смысл: получить «редактирование видео через мозг», где управляющими параметрами являются реальные нейронные типы и их активность.

---

## 3. Closed brain-generator loop

Цель: замкнуть frozen brain и 13B в автономный цикл без нового обучения.

Pipeline:

`arbitrary state → 13B → video → frozen brain → new state → 13B → ...`

Запустить 10–20 итераций из разных начальных состояний:
- random synthetic state;
- structured motion state;
- edited T4/T5 state;
- neuron-noise state.

Измерять:
- round-trip error на каждой итерации;
- изменение state между итерациями;
- изменение видео;
- сходимость к fixed point / attractor;
- повторяемость attractor для разных seed и initial states.

Смысл: проверить, к каким визуальным и нейронным состояниям система сама стремится при многократном цикле `brain ↔ generator`. Это уже не обычная inversion-задача и может показать устойчивые attractors всей связки.

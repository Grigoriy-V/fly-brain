# Mixed Brain-State Video Generation
## Идея проекта / эксперимента

## Суть

Использовать разные типы нейронной активности в зрительной системе мухи как **независимые условия для генерации видео**.

Вместо обычной схемы:

`одно внутреннее состояние → восстановить вызвавшее его видео`

использовать несколько состояний одновременно:

`состояние типа A + состояние типа B + состояние типа C → найти видео, совместимое со всеми условиями`

Это превращает текущий encoder inversion в инструмент для **смешивания, редактирования и управления визуальным содержимым через внутренние состояния connectome-constrained модели**.

---

## Основная идея

Разные типы нейронов несут разные аспекты визуальной информации.

Очень грубо:

- `R / L` — яркость, контраст, общая пространственная структура;
- `Mi / Tm` — промежуточные пространственно-временные признаки;
- `T4 / T5` — локальное движение, направление и optic flow.

Это позволяет попробовать задавать разные источники информации на разных уровнях.

Например:

`L1 / L3 ← клип A`

`T4 / T5 ← клип B`

и затем искать видео, которое максимально хорошо воспроизводит оба набора состояний.

---

## Возможные режимы

### 1. Interpolation внутри одного типа

Взять состояние одного типа нейронов от двух разных клипов:

`T4a_target = 0.5 × T4a(A) + 0.5 × T4a(B)`

и посмотреть, какое видео соответствует промежуточному состоянию.

Это самый простой и контролируемый вариант.

---

### 2. Appearance from one clip + motion from another

Взять ранние зрительные представления из одного видео, а motion-related состояния из другого.

Например:

`L1 / L3 ← лес`

`T4 / T5 ← другое видео с сильным движением`

Цель — проверить, можно ли разделить:

- внешний вид сцены;
- её движение;
- spatial structure;
- temporal dynamics.

---

### 3. Different stages from different clips

Более общий вариант:

`L1 ← clip A`

`Mi1 / Mi4 ← clip B`

`T4 / T5 ← clip C`

После этого inversion ищет одно видео, максимально совместимое со всеми выбранными условиями.

Это уже не reconstruction, а **hybrid neural conditioning**.

---

### 4. Artificial neural edits

Не обязательно брать состояние из готового видео.

Можно вручную менять внутреннюю активность:

- усиливать `T4a`;
- подавлять `T5`;
- интерполировать состояние `Mi1`;
- усиливать или ослаблять отдельный тип;
- добавлять структурированный шум;
- менять временной профиль активности.

После этого генератор показывает:

> какое видео наиболее совместимо с таким искусственно изменённым состоянием мозга.

---

## Формулировка задачи

Пусть для каждого выбранного типа нейронов есть target state.

Тогда генерация решает приблизительно такую задачу:

`Loss = w1 × Loss(L1) + w2 × Loss(Mi1) + w3 × Loss(T4/T5) + regularization`

где веса позволяют управлять важностью разных типов.

Видео оптимизируется через frozen connectome-constrained encoder.

---

## Ключевая техническая проблема

Активности разных типов нельзя просто складывать без нормировки.

Разные группы отличаются по:

- числу нейронов;
- масштабу активности;
- variance;
- temporal dynamics;
- чувствительности inversion loss.

Поэтому loss должен быть нормирован по типу или группе, иначе одна population может полностью подавить остальные.

---

## Биологическое ограничение

Разные уровни зрительной системы не являются независимыми слоями.

Состояние `L1` от одного видео и состояние `T4` от другого может быть **невозможной комбинацией**, которая никогда не возникает при реальном визуальном входе.

Это не делает эксперимент бесполезным.

В таком случае inversion отвечает на другой вопрос:

> какое видео является наиболее совместимым с искусственно заданным набором внутренних ограничений?

Такой режим лучше описывать как **counterfactual brain-state generation**, а не как reconstruction реального восприятия.

---

## Три класса экспериментов

### Reachable mix

Смешиваются близкие или интерполированные состояния, которые вероятно остаются достижимыми реальным входом.

Пример:

`T4a(A) ↔ T4a(B)`

---

### Hybrid control

Разные части состояния берутся из разных клипов.

Пример:

`L1/L3(A) + T4/T5(B)`

Это исследует разделение appearance и motion representations.

---

### Counterfactual brain edit

Состояние меняется вручную и может вообще не соответствовать никакому естественному визуальному стимулу.

Пример:

`T4a × 2`

или

`T5 = 0`

После этого ищется наиболее совместимое видео.

---

## Первые эксперименты

### Experiment A — Single-type interpolation

Интерполировать состояние одного типа между двумя видео и проверить:

- плавно ли меняется output;
- насколько линейно меняется motion / appearance;
- сохраняется ли compatibility score.

---

### Experiment B — Appearance / Motion split

Взять:

`L1/L3 ← clip A`

`T4/T5 ← clip B`

и посмотреть:

- сохраняется ли spatial appearance от A;
- переносится ли motion structure от B;
- какие группы доминируют в результате.

---

### Experiment C — Gain editing

Взять один clip и искусственно изменить одну population:

- `T4a × 0.5`;
- `T4a × 2`;
- `T5 × 0`;
- `Mi4 × 1.5`.

Сгенерировать видео для каждого варианта и сравнить изменения.

---

### Experiment D — Multi-source hybrid

Использовать три разных источника:

`early vision ← A`

`intermediate vision ← B`

`motion ← C`

Это наиболее свободный генеративный режим.

---

## Что можно исследовать

Такая система позволяет задавать вопросы:

- где в зрительной системе хранится appearance;
- какие populations больше влияют на motion;
- насколько независимо представлены разные свойства сцены;
- какие combinations внутренних состояний совместимы;
- где начинаются конфликты между уровнями;
- насколько легко искусственно управлять visual representation через отдельные cell types.

---

## Возможный результат

Из обычного encoder inversion можно получить **brain-state-conditioned video generator**, где внутренние состояния зрительной системы выступают как набор controllable latent conditions.

Концептуально:

`brain state editing → differentiable inversion → video`

То есть не просто восстановление изображения из мозга, а **управляемая генерация через нейронные представления connectome-constrained модели**.

---

## Короткая формулировка

> Использовать состояния разных типов нейронов зрительной системы как независимые условия генерации: смешивать их между клипами, интерполировать, усиливать, подавлять и получать видео, наиболее совместимое с выбранным набором внутренних состояний.
